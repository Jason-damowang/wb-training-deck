 PART 01 · 开场
 先记一个公式： 任务 = 目标 + 材料 + 约束 + 交付物 
 WorkBuddy 能不能跑通，90% 取决于你这句话写得全不全。点一下下面四个要素，看它们怎么拼成一条能跑的指令。
 目标
 把这份数据按区域和月份交叉对比
 想让它最终做到什么。动词要具体。
 +
 材料
 资料库里 7 月的销售明细表
 东西在哪。给路径、文件名、范围。
 +
 约束
 只看华东和华南，同比下滑超过 10% 才标出来
 边界条件。口径、阈值、范围。
 +
 交付物
 输出成一页 HTML 看板，图上标注数据来源
 要拿到什么。格式、结构、长度。
 拼起来就是一条能跑的指令
 !
 别写「帮我整理一下」 ——没有材料、没有交付物，它只能猜你要什么。
 !
 缺什么就补什么 ——数据不全时明确说「数据不足就标注出来」，不要让它编。
 ✓
 一次说不全没关系 ——它可以追问，你也可以边看结果边补条件。

 把一次任务跑顺， 就这四个动作 
 大部分「跑不通」，都卡在第二个和第三个动作：材料给得不完整，或者跳过了中间确认。
 01 
 选能力

 给材料 
 给原始文件，不做预加工 
 03 
 看中间结果

 04 
 收口沉淀 
 结果和口径一起存下来 
 01 选能力
 对着 11 项能力看一眼，判断这活儿该用哪个。判断错了没关系，它会提醒你换一种做法。
 ✗ 帮我把这些整理一下
 ✓ 用资料库检索，把这几份材料串成目录页
 02 给材料
 给原始文件，不要自己先算一遍、删一遍。你提前做的加工，反而会让它看不到全貌。
 ✗ 先手动筛好再给它
 ✓ 直接给原始明细，让它按你给的口径筛
 03 看中间结果
 先让它出大纲、出口径、出数据情况，你确认之后再生成成品。这一步省掉，返工最多。
 ✗ 直接要最终文件
 ✓ 先要结构，确认后再要成品
 04 收口沉淀
 做完就存。结果、口径、提示词一起放进资料库或 Skill，第二次就只剩一句话。
 ✗ 用完就关掉会话
 ✓ 把这个流程存成 skill，下次我说任务名就跑
