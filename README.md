## 内容来源与改写原则（v3.0 新增的 5 页）

内容来自总裁班演讲 deck（`wb-ceo-deck` v3-2.html）第 08–12 页，**不是复制粘贴**：

1. **色彩与视觉重做**：总裁班版是深蓝底 + 金色（`#0A2239` / `#12365C` / `#C9A063`），培训版是白底 + 薄荷绿（`#00B87C`）。新页复用既有设计变量与组件（`.goal / .tips / .blk / .pill`），只新增少量岗位场景组件（`.pods / .chain / .bub / .cap2 / .five / .quote / .src`，源码见 `scripts/v3-pages.html`）。
2. **口径改为全员视角**：去掉「订阅 / SLA / 多租户 SaaS / ROI」等销售话术；保留数据与来源（Salesforce 28%、APQC 6.4 天月结、Asana 60%、Gartner 1,290 万美元），统一放页脚小字。
3. **密度降一档**：与培训版单页 40–80 字的节奏对齐，总裁班版每页 300+ 字压成「要点 + 1 个案例 + 1 句收口」。
4. **客户名已脱敏**：销售分身页案例为「某家纺客户」（原总裁班版为具体客户名），老板分身页为「张总 · 家纺周一决策会」。

## 改内容时的注意点

1. **只改当前版本的 HTML**；`docs/` 是派生产物，改完跑 `python3 scripts/extract-docs.py`。
2. **提示词不在 `.txt` 容器里**。页面上的提示词由 `data-pmt` 属性提供、JS 打字机动画渲染，`<div class="txt">` 是空的。改提示词要搜 `data-pmt="`。
3. **截图是内嵌 base64**，共 29 处；v3.0 新增的 5 页没有截图。
4. **加/删/移页要同步的数字**：封面副标题「N 页里」、封面统计页数、每个页脚的 `NN` 与 `/ N`、结尾页「共 N 页」、PART 编号、**以及页脚版本号**。顶部页码控件 `#pgnum` 由 JS 按实际页数渲染，不用改逻辑。
5. **删页要查引用**：删「公式页」时就出现过结尾页「用那句公式写一遍」指向失效内容的连带问题 —— 改前先搜被删页面的关键词（如「公式」「四要素」）。
6. **移动/删除页用脚本，不要手工剪切**：页块之间的注释、末页之后的 1.5 MB 数据包与灯箱脚本容易被漏掉。参考 `scripts/build-v3.1.py`（切块 → 重排 → 重编页脚 → 显式接回 suffix）。
7. **改完必须做溢出检查**：舞台固定 1280×720，内容超了会被 `.page{overflow:hidden}` 静默裁掉。用 headless Chrome 测每页元素实际底边与卡片下沿的差值（做法见 CHANGELOG）。
8. 版本升级请**另存新文件**、更新 `index.html` 跳转目标，并把页脚版本号一并更新。
