## 新增页的来源与改写原则

内容来自总裁班演讲 deck（`wb-ceo-deck` v3-2.html）第 08–12 页，**不是复制粘贴**：

1. **色彩与视觉重做**：总裁班版是深蓝底 + 金色（`#0A2239` / `#12365C` / `#C9A063`），培训版是白底 + 薄荷绿（`#00B87C`）。新页复用培训版既有设计变量与组件（`.goal / .tips / .blk / .pill`），只新增少量岗位场景专用组件（`.pods / .chain / .bub / .cap2 / .five / .quote / .src`，见 `scripts/v3-pages.html` 尾部 CSS）。
2. **口径改为全员视角**：去掉「订阅 / SLA / 多租户 SaaS / ROI / 投 1 拿回 3-5 倍」等销售话术；保留数据与来源引用（Salesforce 28%、APQC 6.4 天月结、Asana 60%、Gartner 1,290 万美元），统一放页脚小字。
3. **密度降一档**：总裁班版销售/财务/老板三页原文各 300+ 字，改为「要点 + 1 个案例 + 1 句收口」，与培训版单页 40–80 字的节奏对齐。
4. **新页没有截图**：总裁班 deck 08–12 页本身无图（纯 CSS 卡片/流程条），培训版能力页靠截图撑版面 —— 新页用流程条、对话气泡、五格卡片承担信息密度。

## 改内容时的注意点

1. **只改当前版本的 HTML**；`docs/` 是派生产物，改完跑 `python3 scripts/extract-docs.py workbuddy-training-v3.0.html` 同步。
2. **提示词不在 `.txt` 容器里**。页面上的提示词由 `data-pmt` 属性提供、JS 打字机动画渲染，`<div class="txt">` 是空的。改提示词要搜 `data-pmt="`，不要搜页面文字。
3. **截图是内嵌 base64**，共 29 处；新页没有截图（无 `data:image`）。
4. **加/删/移页要同步的数字**：封面副标题「N 页里」、封面统计页数、每个页脚的 `NN` 序号与 `/ N`、结尾页「共 N 页」、以及 PART 编号。顶部页码控件 `#pgnum` 是 JS 按实际页数渲染的，不用改逻辑。
5. **页脚编号由构建脚本按顺序写入**（`scripts/build-v3.0.py` 的「页脚编号重排」步骤），手工插页后建议重跑同类脚本，避免序号错位。
6. **改完必须做溢出检查**：培训版舞台固定 1280×720，`.stage-in` 内容区高 634px，内容超了会被 `.page{overflow:hidden}` 裁掉且不报错。用 headless Chrome 测 `si.scrollHeight > si.clientHeight`（做法见 CHANGELOG v3.0 的「校验」一节）。
7. 版本升级请**另存新文件**并更新 `index.html` 的跳转目标。
